# COUPLER 双角色交易原型 — 设计文档

> 版本：v1.0 | 日期：2026-04-08 | 状态：已确认

---

## 1. 目标

构建一个高保真可点击 HTML 单文件原型，用于向供应商和采购商演示 COUPLER 平台的核心交易流程（询价→报价→订单）。

---

## 2. 原型范围

### 角色视角
- **双角色切换**：采购商视角 + 供应商视角，可同框对比
- 切换时整个界面联动，展示"同一个询价，买卖双方看到什么"

### 页面清单（共12页）

| # | 页面 | 角色 | 核心交互 |
|---|------|------|----------|
| 1 | 首页/产品列表 | 采购商 | 标准件多维搜索，规格卡片+参数 |
| 2 | 产品详情 | 采购商 | 尺寸图+规格参数表+供应商信息+立即询价 |
| 3 | 发起询价单 | 采购商 | 选产品→填数量→提交询价 |
| 4 | 我的询价 | 采购商 | 询价单列表+状态（待报价/已报价/已关闭） |
| 5 | 收到的询价 | 供应商 | 采购商发来的询价通知列表 |
| 6 | 发起报价 | 供应商 | 填写单价+交期+备注，提交报价 |
| 7 | 我的报价 | 供应商 | 报价单管理+报价状态（待接受/已接受/已拒绝） |
| 8 | 收到的报价 | 采购商 | 多供应商报价对比表，选择最优 |
| 9 | 确认订单 | 采购商 | 选择最优报价→生成正式订单 |
| 10 | 我的订单（双侧） | 双方 | 订单列表+状态流转（已确认→生产中→已发货→已完成） |
| 11 | 消息通知 | 双方 | 站内消息（询价到达/报价到达/订单变化） |
| 12 | 供应商入驻 | 供应商 | 企业信息+能力标签录入+提交 |

---

## 3. 技术方案

### 架构
- **单文件 HTML**：所有页面通过 JS 切换 DOM visibility 实现，无刷新
- 纯原生 HTML/CSS/JS，无框架依赖，文件体积小，可直接浏览器打开

### UI 框架
- Tailwind CSS（CDN引入），工业蓝+科技白配色
- CSS Grid + Flexbox 布局，移动端响应式（media query）

### 数据层
- Mock 数据内嵌 JS，模拟完整业务流程
- 状态存储在内存对象中，支持页面间数据联动
- LocalStorage 可选（用于演示中刷新保持状态）

## 5. 状态设计

### 询价单状态
`草稿` → `已发送` → `有报价` → `已关闭`

### 报价单状态
`待接受` → `已接受` → `已拒绝` → `已过期`

### 订单状态
`已确认` → `生产中` → `已发货` → `运输中` → `已到货` → `已完成`

---

## 6. 演示脚本建议

1. **采购商开场**：搜索螺栓→看产品详情→发起询价（选3款）
2. **切换供应商**：收到新询价→填写报价→提交
3. **切换回采购商**：查看3家报价→对比→选择最优→生成订单
4. **订单跟踪**：双方查看订单状态变化
5. **消息通知**：演示状态变化触发站内消息
